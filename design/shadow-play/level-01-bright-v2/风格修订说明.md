# 小兔摘月｜明亮纸影版 v2

状态：基于试玩反馈的新视觉方向，待复核。此轮先出第一关初始态设计稿，未替换现有可玩版本。

## 反馈对应的调整

玩家反馈“有点瘆人、像鬼故事、太暗”。以下为对当前画面的设计判断，后续仍需让反馈者看图确认。

| 当前可能造成不适的元素 | 修订 |
| --- | --- |
| 深木框、暗色操作台占据大面积 | 奶油宣纸做页面底色，浅枫木仅承担舞台结构 |
| 强背光与四角压暗形成夜戏感 | 全画面柔和环境光，操作台也清楚明亮；月亮和灯只作为局部暖色点缀 |
| 旧皮革斑驳、密集纹样、凸出的铜关节 | 轻薄染色纸质感，少量镂空，小型纸铆钉 |
| 细长肢体、偏人的五指、凝视感眼睛 | 圆润四肢、兔爪、小棕眼和轻微笑容 |
| 厚重红幕、仿古金属按钮 | 少量轻盈珊瑚红布帘，简洁圆角按钮 |

## 视觉目标

让玩家先感到“想亲手摆弄这个小戏台”。保留侧面皮影、镂空花纹、可见关节和灯—皮影—影幕的关系，避免改成泛化的萌宠界面。

大面积用色：奶油纸 #FFF5E6；浅枫木 #DBB988；珊瑚 #D98570；灰豆绿 #94AD94。文字使用可读的可可棕 #6D5145，强调色为 #B95743。仅美术简报色值，最终以实际文字对比度核验为准。

初始态仍展示够不到月亮的兔影，实体与投影保持同一举爪姿态。玩法保持拖灯改变投影大小。

## 看稿后要验证的事

1. 让原反馈者先说第一感受，再询问是否还有“不舒服、阴暗、像鬼故事”的感觉，避免只问“是不是更好看”。
2. 能否继续认出这是皮影戏，能否指出灯是唯一可操作对象。
3. 留意是否过于幼儿化、是否弱化了镂空纸影特色。不能仅凭亮色就判断问题已解决。
